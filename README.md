# VD01. Введение в веб-разработку. Основы HTML
Базовый пример работы с HTML, включающий две страницы:  

1. **Главная страница (`index.html`)**  
   - Содержит таблицу с блюдами.  
   - Каждое блюдо имеет название, оценку, ссылку на рецепт и изображение.  
   - Ссылки ведут на отдельную страницу с рецептами, используя якоря (`#id`).  
 
2. **Страница с рецептами (`recipes.html`)**  
   - Содержит описания блюд, структурированные с помощью заголовков (`<h2>`) и параграфов (`<p>`).  
   - Каждое блюдо имеет уникальный `id`, что позволяет создавать якорные ссылки.
